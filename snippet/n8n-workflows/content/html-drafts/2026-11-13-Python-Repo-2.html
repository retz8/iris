def _resolve_verb(user_segments: list) -> str: prose = [_diff_prose(seg) for seg in user_segments] if not prose: return _DEFAULT_VERB verb = _explicit_verb(prose[0]) if verb: return verb if _reads_as_question(prose[0]): return "ask" for older in prose[1:]: verb = _explicit_verb(older) if verb: return verb return _DEFAULT_VERB



Before scrolling: what does this do?

The Breakdown

  • What it does: Picks which PR-Agent command a conversation should run: an explicit verb in the newest user message wins, then a question there means "ask", then the first explicit verb in older messages, and otherwise it falls back to "review".
  • Key responsibility: It sits in PR-Agent's MOSAICO server, which lets other AI agents call PR-Agent over the A2A protocol with a PR link or raw diff. Follow-up messages arrive with history, and this decides what the latest one means.
  • The clever part: Each message first goes through _diff_prose, which strips any pasted diff. Without it, a ternary or regex containing "?" inside the patch would make every diff look like a question and silently turn reviews into "ask".
