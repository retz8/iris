static void fwht_inplace(float* buf, size_t n) { for (size_t step = 1; step < n; step *= 2) { for (size_t i = 0; i < n; i += step * 2) { for (size_t j = i; j < i + step; j++) { float a = buf[j]; float b = buf[j + step]; buf[j] = a + b; buf[j + step] = a - b; } } } }



Before scrolling: what does this do?

The Breakdown

  • What it does: Applies the Fast Walsh-Hadamard Transform in place: for block sizes 1, 2, 4 and up, it replaces each pair (a, b) with (a + b, a - b), mixing every input into every output in n log n steps.
  • Key responsibility: It powers Faiss's HadamardRotation, a cheap stand-in for a random rotation matrix. Three rounds of random sign flips plus this transform spread a vector's energy evenly across dimensions before quantization, without storing or multiplying a d-by-d matrix.
  • The clever part: It never multiplies, only adds and subtracts, so each pass scales the vector's norm by sqrt(2) and three full transforms by p^(3/2). The caller skips per-pass normalization and fixes the scale once at the end with a single multiply.
