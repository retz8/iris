- file_intent: Deduplicating crawl request scheduler
- breakdown_what: Fingerprints an incoming crawl request, drops it if an identical one was already seen, then pushes it onto an async priority queue as a (negated priority, counter, request) tuple, while mirroring it in a dict for checkpoints.
- breakdown_responsibility: It is the front door of Scrapling's spider engine: every link a spider yields passes through here, so this method decides crawl order, prevents revisiting pages, and keeps a snapshot of pending work so a paused crawl can resume.
- breakdown_clever: The counter does double duty. It breaks priority ties so heapq never compares two Request objects, and because the scheduler creates it counting down (step=-1) for depth-first crawls, the same tuple turns FIFO into LIFO.
- project_context: Scrapling is an open-source Python framework that combines fast HTTP fetching, stealth browsers, adaptive parsing and concurrent spiders in one library, and ships an MCP server so AI agents can browse and extract data with it.

```python
async def enqueue(self, request: Request) -> bool:
    """Add a request to the queue."""
    fingerprint = request.update_fingerprint(
        self._include_kwargs,
        self._include_headers,
        self._keep_fragments,
    )

    if not request.dont_filter and fingerprint in self._seen:
        log.debug("Dropped duplicate request: %s", request)
        return False

    self._seen.add(fingerprint)

    # Negative priority so higher priority = dequeued first
    counter = next(self._counter)
    item = (-request.priority, counter, request)
    self._pending[counter] = item
    await self._queue.put(item)
    return True
```

```python
def _resolve_verb(user_segments: list) -> str:
    prose = [_diff_prose(seg) for seg in user_segments]
    if not prose:
        return _DEFAULT_VERB
    verb = _explicit_verb(prose[0])
    if verb:
        return verb
    if _reads_as_question(prose[0]):
        return "ask"
    for older in prose[1:]:
        verb = _explicit_verb(older)
        if verb:
            return verb
    return _DEFAULT_VERB
```
